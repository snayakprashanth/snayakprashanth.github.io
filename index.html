01. About

I'm a senior full-stack engineer who likes owning a feature from the screen to the database. On the frontend I build responsive, reusable UIs in React and Angular, with component libraries, micro-frontends and data visualization in D3.js.

On the backend I design REST and GraphQL APIs and microservices in Node.js, secure them with JWT-based auth, and ship them to AWS with Docker and CI/CD. Shared TypeScript models tie the two together. I mentor engineers, lead code reviews, and use an AI-assisted workflow — GitHub Copilot, Windsurf and prompt engineering — to ship faster.

  • React & Angular UIs
  • Node.js APIs & microservices
  • End-to-end TypeScript
  • Micro-frontends & design systems
  • Cloud delivery on AWS
  • Mentoring & AI-assisted dev
